# PERMANENT QR STUDIO SPECIFICATION

## 1. Core Product Promise
Printed once. Connected forever. The physical QR code points to a stable restaurant URL (`/menu/{slug}`) and never changes when dishes, prices, descriptions, or templates are modified.

## 2. Real-Time QR Invariance Proof Component
Integrated inside `src/pages/app/QrCenter.tsx`:
- Provides an interactive "Simulate Menu Update (₹280 → ₹350)" button.
- Demonstrates live database price updates while proving that the generated QR code and destination URL remain 100% unchanged.
